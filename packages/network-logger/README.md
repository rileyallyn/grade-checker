# network-logger

`npm install @grade-checker/network-logger`

A simple package for logging fetch requests in a React Native app.

Syntax highlighting can be used by installing `@grade-checker/network-logger-syntax`.
Build from the monorepo root with `pnpm exec turbo run build --filter=@grade-checker/network-logger...` before running the app, or rely on `pnpm publish` / `prepublishOnly`, which compiles `dist/`.
